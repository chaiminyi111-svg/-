Telegram Bot 正在检查配置…

保存前会调用 Telegram getMe 验证。Token 只保存在服务器数据库，不会回显到页面。

怎么获取 Token？

在 Telegram 搜索 @BotFather，发送 /newbot，按提示创建机器人，复制它返回的 Token。

WhatsApp Cloud API 正在检查配置…

保存前会调用 Graph API 校验 Token 和 Phone Number ID。留空的密钥字段保持原值，页面不会回显密钥。

Webhook 地址

/webhook/whatsapp

在 Meta 后台把回调地址填成上面的完整 HTTPS 地址，并填写相同的 Verify Token。App Secret 用于校验消息签名。

翻译服务 正在检查配置…

官方 API 需要 Key，保存前会验证。其余通道均无需 Key：Google 网页翻译、Chrome 翻译接口、MyMemory。它们都不是 Google 官方 API，可能限流或失效；MyMemory 单次最多约 500 字符，适合作为备用。

怎么获取 Key？

在 Google Cloud Console 启用 Cloud Translation API，创建 API Key 后填入这里。Key 仅用于服务端调用，不会发送到浏览器。没有 Key 时可在上方切换任意一个免费备用通道。

AI 自动回复 正在检查配置…

支持 OpenAI、DeepSeek、通义千问、智谱等 OpenAI 兼容接口。Key 只保存在服务器数据库，不会回显到页面。AI 只处理已分配给客服的会话，并受员工权限和员工自己的 AI 开关控制。

回复模式说明

只生成建议：AI 生成草稿，客服确认后发送。自动回复：每条新客户消息自动回复。仅首次接待：只在还没有人工回复时自动回复一次。非工作时间：只在设置的工作时间之外自动回复。

我的 AI 助手

AI 只处理分配给你的会话；你可以单独开关和选择回复模式。
